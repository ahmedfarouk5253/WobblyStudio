Reef Drop

Ocean Merge Game

Reef Drop is a cozy drop-and-fall merge game set in a colorful coral reef. Drop sea creatures into the tank, merge matching ones together, and grow your reef from tiny plankton all the way up to the biggest creatures of the deep.
