Arrow Voyage

Arrow Escape Puzzle

Tap an arrow. If its path is clear, it flies away. Clear the board to win. Arrow Voyage is a calm, fair arrow escape puzzle: easy to learn, surprisingly deep, and made to be relaxing. Every level you clear paints part of a travel postcard, across 20 hand-painted destinations with Pip, the little explorer bird.
