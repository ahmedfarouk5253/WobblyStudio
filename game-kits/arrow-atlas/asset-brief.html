Arrow Atlas ➜ Asset Brief

Every image the game needs, with the exact file name, folder, pixel size, aspect ratio, transparency and a ready-to-paste prompt. Generate each file, save it under the path shown, and give the folders to Claude Code. The puzzle board, arrows, dot grid, buttons and particles are drawn in code, so they are not on this list.

How to use this page

  1. Generate the two Reference images first. Upload them as reference images for everything else, so Pip and the style stay identical.
  2. Work through P0 first (needed to play), then P1 (needed to launch), then P2 (optional).
  3. Copy each prompt, generate, and save the image with the exact path shown. Bigger is fine if the ratio matches.
  4. The dashed red marks on a frame show where content must not go: the icon safe circle and the caption band on screenshots.
  5. Tick Done as you go. Ticks are saved in this browser only.
  6. Drop assets/, store/ and assets_src/ into the project root and tell Claude Code: “New assets are in, run the asset check and wire them in.”
