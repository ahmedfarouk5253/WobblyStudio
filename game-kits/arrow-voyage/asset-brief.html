Arrow Voyage ➜ Asset Brief

Every image the game needs, with the exact file name, the aspect ratio to generate at, the final size and a ready-to-paste prompt. Two looks: soft 3D for Pip, icons and props, and painterly for scenes. The puzzle board, arrows, dot grid, buttons and particles are drawn in code, so they are not on this list.

Why the first batch looked flat

The tool drew the images with code (shapes like circles and triangles) instead of using an image model. The first prompts also asked for “flat vector” art at exact pixel sizes with transparency, which pushed it that way.

Fix: open an image generator in image mode, paste one prompt at a time, and generate 2–4 variants. Don’t ask a chat agent to “make all the files from this page”.

How to use this page

  1. Generate pip_master first (try 4–8 variants and pick the cutest), then style_props.
  2. For every Pip image, attach pip_master as the character reference. For every icon, attach style_props.
  3. Set the generator to the Generate as ratio and the best quality. Exact pixels don’t matter; Claude Code crops and resizes.
  4. Cutout images come out on plain light grey. Remove the background in your generator, or leave it and Claude Code removes it.
  5. Skip anything marked Claude Code makes this.
  6. Save with the exact path shown, tick Done (saved in this browser only), then drop assets/, store/ and assets_src/ into the project and tell Claude Code: “New assets are in, run the asset pipeline and wire them in.”
